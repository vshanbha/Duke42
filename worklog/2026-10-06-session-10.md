## What Was Done

### 1. Diagnosed plugin load failure `err_aca758e7`
- Located the matching server log entry (`~/.local/share/opencode/log/opencode.log`,
  run 722aa801): `NpmInstallFailedError ... ENOENT .../factory-hooks.ts/package.json`
- Root cause: the plugin was a **V1 plugin running on OpenCode V2.0.23** —
  default export was a function, V2 requires `Plugin.define({ id, setup })`
  (sibling errors `err_270fd4c5`/`err_96f02f64`: `SchemaError Expected object at ["default"]`)

### 2. Migrated plugin to V2 API (`.opencode/plugin/factory-hooks.ts`)
- `export default Plugin.define({ id: "factory-hooks", setup })`
- `tool.execute.before/after` → `ctx.tool.hook(...)`; `event` → `ctx.event.subscribe()`; `dispose` → cleanup returned by `setup`
- Dropped the V1 `chat.message` session→agent map — V2 tool hook events carry `agent` directly
- Idle-event subscription filters by `location.directory` (server stream is global)

### 3. Config + dependency migration
- Removed the `plugin` config key from `opencode.json` entirely: V2 auto-discovers
  `.opencode/plugin/`; the raw relative spec was being routed to the npm installer (the reported error)
- `.opencode/package.json`: `@opencode-ai/plugin@1.17.13` → `@opencode/plugin@2.0.23`

### 4. Fail-open cwd bug found by live parity eval (second root cause)
- Pre-fix live eval: implementer wrote `src/test/java/ParityProbeTest.java` — gate silent
- Cause: `scripts/lib/config.sh` resolves factory.yaml via `git rev-parse` in the
  **script's cwd**; shared server `PWD` was unrelated → patterns empty → exit 0
- Fix: plugin passes `cwd: directory` to `execFile` (denial script + gofmt)
- Post-fix live eval: `Error: DENIED: implementer role cannot edit test files (*_test.go)` — no file created
