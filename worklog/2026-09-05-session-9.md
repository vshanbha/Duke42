## Lessons Learned

1. **Check `origin` before calling branches stale.** Local `dev` looked "ahead"
   but was actually behind `origin/main` — the pending work was a sync, not a PR.
2. **One PR per concern, fixups on the same branch.** Opening PR #13 for work
   the maintainer wanted on PR #12 wasted a review cycle; the AGENTS.md rule
   exists for exactly this.
3. **Shell runner ordering is implicit.** `springShellApplicationRunner` has no
   `@Order` (LOWEST_PRECEDENCE) — verified via `javap` on 4.0.3 jars; pinned
   with an `@Order` assertion test, not just a comment.
4. **`getNonOptionArgs()` distinguishes shell commands from Spring options.**
   `--rag.enabled=true` stays an option (auto-start proceeds); `help` is a
   non-option arg (Shell handles it).
5. **Test-count drift needs a sweep every time.** `grep -rn "63 tests"` across
   `*.md` (excluding `worklog/`) catches the stragglers the reviewer will find.
