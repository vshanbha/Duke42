## Lessons Learned

1. **Sandbox wrappers are necessary** — `GlobTool`/`GrepTool` from `spring-ai-agent-utils` accept arbitrary `path` arguments. Without wrappers, an LLM can glob/grep outside the project directory. `FileSystemTools` has built-in `allowedDirectory` enforcement, but Glob/Grep do not.

2. **`ToolCallbacks.from()` works with POJO `@Tool` methods** — The sandbox wrappers are plain POJOs with `@Tool`-annotated methods, same as the original tools. Spring AI's `ToolCallbacks.from()` scans for `@Tool` annotations and wraps them into `ToolCallback[]`.

3. **Package-private classes cause cross-package test issues** — `UserVisibleToolCallback` is package-private in `com.example.cliai.agent`, so tests in `com.example.cliai.agent.tools` can't access it. Moved relevant test to correct package or used raw `ToolCallback` interface.

4. **`commit-message-lint.sh` checks every commit** — Not just the tip. All commits in `main..HEAD` must pass. Squashing to a single commit is the simplest fix when older commits have lint issues.

5. **Worklog commits should be separate** — Don't bundle worklog entries with feature commits. Keep PRs focused on one concern.
